# Study1 E1 共用隔離驗收（本機測試，不是正式 GAS 網站）

使用 Node.js 22（22.13 以上），解壓縮後在套件根目錄執行：

    node scripts/study1-v2-uat-shared.cjs

瀏覽器開啟 http://127.0.0.1:8765/ 。服務只監聽本機，不要轉發或開放外網。可在 Edge 普通與 InPrivate 各開一個視窗，選 TEST_01/TEST_02，模擬 OTP 12345678，兩者同時選最後一個同時段名額、暫留；只有一個成功。重新載入可看到名額變化。使用勝方閱讀五頁測試 PDF、畫虛構筆跡、完成確認與下載。保存本案密鑰；新視窗貼入並「重新讀回本案」可下載同一份完整文件。停止服務後，使用終端列出的測試資料夾路徑作為唯一參數重新啟動，可讀回同案。不要輸入真實身分/姓名/聯絡資料/簽名/研究文件。不同虛構身分各只能建立一案；測試完新建空目錄可開新一輪。

單一獨立 SQLite 交易保存預約確認、PDF 完整位元組、來源及簽署 SHA、可信本機伺服器時間、案件識別；資料夾限制及密鑰驗證；不接入 Google、正式研究資料、電子郵件或遠端部署。不使用真實資料；這是本機工程驗收，未驗 GAS LockService 或正式 Sheets/Drive。正式 GAS V2/Repo 主架構不變。部署阻塞另處理。
